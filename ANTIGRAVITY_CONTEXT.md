## 2. Ground-Truth Rules from `Mithor-Platforms`

1. **Monorepo Layout (`apps/<TOKEN>/`):**
   * `apps/FEP`: Vite 6 + React 18 + Tailwind 3 + `jsPDF` + `recharts` (`npm run dev` on port `5173`, `npm run build`, `npm test` via `vitest run`).
   * `apps/BFF`: FastAPI + MongoDB (`motor`) on port `8000` (Red Zone — locked).
   * `apps/AI`: Python 3.12 + FastAPI + Poetry (`poetry run pytest tests/unit/ide -q` runs deterministic mock-mode tests with zero API keys).
   * `apps/Mobile` & `apps/Jobs`: Kotlin Multiplatform mobile app and macro-data ingestion jobs (Red Zone — locked).
2. **Branching & CI Lane Rules:**
   * **`develop`** is the integration/staging branch (merges auto-deploy touched `apps/<TOKEN>/**` lanes to staging).
   * **`main`** is production (deployed via release tags cut by Kris/Ukarky).
   * All branches created by this harness MUST branch from and target **`develop`** (`philipp/YYYY-MM-DD-<slug>` -> `develop`).
3. **HARD RULE #1 — Zero AI Attribution:**
   * Per `Mithor-Platforms/CLAUDE.md`: **No AI attribution anywhere.** No `"Claude"`, no `"DeepSeek"`, no `"Generated by"`, no `Co-authored-by` in commits, PR titles/bodies, code comments, or docs.
4. **i18n Parity Rule in `apps/FEP`:**
   * `apps/FEP/src/__tests__/i18nParity.test.js` enforces key parity across `src/locales/de.json`, `src/locales/en.json`, and `src/locales/fr.json`. Any new or renamed translation key in `de.json` must also be updated in `en.json` and `fr.json`.

## 3. Three-Zone Guardrail Policy (`config/zones.config.json`)

* **Green Zone (`read_write`):** `apps/FEP/src/**` and `apps/FEP/public/**` (excluding auth/api transport layers). Gates: `fep_build` (`npm run build`), `fep_test` (`npm test`), `visual_snapshot`.
* **Yellow Zone (`guarded_write`):** Pure deterministic IDE math & rules in `apps/AI/app/modules/ide/{constants,parameters,normalize,audit,scoring,rules,pricing,dcf,residual,ratings,report}.py`. Requires a plain-German formula explanation and explicit confirmation from Philipp before editing. Gates: `ide_pytest_golden` (`poetry run pytest tests/unit/ide -q`) + `bff_ai_contract_check`.
* **Red Zone (`blocked`):** `apps/BFF/**`, `apps/Mobile/**`, `apps/Jobs/**`, `apps/AI/app/core/**`, `apps/AI/app/modules/ide/{routes,service,extraction,market}.py`, `servers/**`, `docs/**`, `Assets/**`, `.claude/**`, `.github/**`, `.env*`, and package manifests.

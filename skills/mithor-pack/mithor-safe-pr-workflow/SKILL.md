# Mithor Zero-Git & L1–L4 PR Triage Workflow

Philipp never types Git commands. Translate his natural German phrases into safe, verified lifecycle actions via `dsh-plugin-mithor-guard` and `dsh-plugin-mithor-git-triage`.

## 1. Starting a Task ("Starte neue Aufgabe" / "Neues Thema")
- Call the `mithor_start_task` tool (`dsh-plugin-mithor-git-triage`) with a short English slug derived from Philipp's German request.
- This automatically fetches `origin/develop`, creates a clean branch `philipp/YYYY-MM-DD-<slug>` off **`develop`**, records the pre-task snapshot SHA, and captures a visual baseline if `apps/FEP` is running.
- Confirm to Philipp in German: *"Ich habe einen frischen Arbeitsstand für diese Aufgabe vorbereitet."*

## 2. Verifying Changes Before Completion
Before telling Philipp a change is finished:
1. Run `mithor_verify_changes` (`dsh-plugin-mithor-guard`).
2. Ensure all required gates for the touched zones pass:
   - **Green Zone (`apps/FEP`):** `npm run build` + `npm test` (including `i18nParity.test.js` and `exportValuationPdf.test.js`) + visual diff.
   - **Yellow Zone (`apps/AI`):** `poetry run pytest tests/unit/ide -q` (verifying `Hohetorstraße`, `Clayallee 18`, and `Frankfurter Allee`) + schema contract check.
3. If verification fails 3 times in a row, `mithor-guard` automatically rolls back to the pre-task snapshot and informs Philipp in German that his local workspace was safely restored.

## 3. Opening a Pull Request ("Sieht gut aus, bitte einreichen / PR erstellen")
- Call `mithor_submit_pr` (`dsh-plugin-mithor-git-triage`).
- The plugin automatically:
  1. Verifies that all dirty zones have `PASSED` verification gates.
  2. Classifies the diff into one of four severity tiers:
     - **`[L1: PIXEL / COPY]`** — Styling, Tailwind spacing/colors, or locale strings (`de.json`/`en.json`/`fr.json`). Reviewer: `sarbu`.
     - **`[L2: UI LOGIC / PDF]`** — React state/props, valuation tables, or `exportValuationPdf.js`. Reviewers: `sarbu`, `manish`.
     - **`[L3: IDE FORMULA]`** — Constants, weights, rules `R-01`..`R-08`, or DCF/Residual math in `apps/AI/app/modules/ide/*.py`. Reviewers: `sarbu`, `manish`, `ukarky`.
     - **`[L4: SCHEMA / HIGH RISK]`** — Function signatures, response schemas, or multi-lane (`FEP` + `AI`) changes. Reviewers: `ukarky`, `sarbu`, `manish`.
  3. Strips **all** AI attribution (`Co-authored-by`, `"Claude"`, `"DeepSeek"`, `"Generated by"`) to comply with `Mithor-Platforms/CLAUDE.md` Hard Rule #1.
  4. Pushes the branch and opens a GitHub PR targeting **`develop`** with a bilingual body:
     - **German Summary (`Für Philipp`):** Plain-language summary of what was changed and verified.
     - **English Technical Breakdown (`For Sarbu / Manish / Ukarky`):** Risk badge, CI lane (`FEP` or `AI`), touched files, verification gate results, and formula/UI diff notes.
